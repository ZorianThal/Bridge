Практическое задание: Bridge
Тема

Создание игровой системы персонажей и способностей с использованием паттерна Bridge.

Ситуация

Вы разрабатываете небольшую RPG.

В игре существуют разные персонажи:

Warrior — Воин
Mage — Маг
Archer — Лучник

И разные способности:

PhysicalAttack — физическая атака
FireAttack — огненная атака
IceAttack — ледяная атака

Необходимо сделать систему так, чтобы персонажа можно было легко соединять с любой способностью.

Например:

Воин + физическая атака
Воин + огненная атака

Маг + огненная атака
Маг + ледяная атака

Лучник + физическая атака
Лучник + ледяная атака
Основная задача

Создайте программу с использованием паттерна Bridge.

1. Интерфейс способности

Создайте:

interface IAbility
{
    void Use(string characterName);
}
2. Реализуйте способности

Создайте три класса:

PhysicalAttack
FireAttack
IceAttack

Все они должны реализовывать:

IAbility

Например:

Воин использует физическую атаку!

Маг использует огненное заклинание!

Лучник использует ледяную атаку!
3. Создайте базовый класс персонажа

Создайте абстрактный класс:

abstract class Character

Он должен хранить:

IAbility ability;

То есть персонаж должен получать способность через конструктор.

Пример использования:

Character warrior =
    new Warrior(fireAttack);
4. Создайте персонажей

Необходимо реализовать:

Warrior
Mage
Archer

Все они должны наследоваться от:

Character

У каждого персонажа должно быть собственное имя.

Например:

Воин
Маг
Лучник
5. Создайте метод использования способности

В классе Character должен быть метод:

UseAbility()

Он должен запускать способность, которая была передана персонажу.

Например:

Character warrior =
    new Warrior(fireAttack);

warrior.UseAbility();

Результат:

Воин использует огненную атаку!
Продемонстрируйте работу

В Main() создайте следующие комбинации:

Воин
Воин + физическая атака
Воин + огненная атака
Маг
Маг + огненная атака
Маг + ледяная атака
Лучник
Лучник + физическая атака
Лучник + ледяная атака
